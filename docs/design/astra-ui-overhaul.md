# Sub2API 全站界面重设计

## 方向

日常 API 工作台：先看清真实数据，再完成操作。采用 `design-taste-frontend` 的 Framed sheet（seed 203532617），保留中文系统字体与克制青色。侧栏和顶栏构成浅灰工作框架，内容是一张有轻边界、无阴影的工作纸；深色使用中性炭灰，避免蓝黑背景。不要渐变、装饰图形、虚构统计、彩色图标砖或多层卡片。

## 数据与任务

- 模型目录来自既有接口，模型 ID、来源分组、输入/输出价格、计价单位与阶梯/分时规则必须完整保留。
- 用户首先确认余额、今日调用与支出，然后查看趋势、最近请求及创建密钥入口。
- 管理员首先确认账号、密钥、请求、用户与吞吐情况，再进入账号或分组管理。
- API Keys、账号、分组是日常工作列表；搜索、筛选、列设置、刷新、选择、批量操作、分页保持原绑定。
- 使用量强调时间范围、真实费用与请求明细；设置强调分区、字段标签与保存操作。
- 登录保留所有认证、验证码、OAuth、通行密钥、协议和注册开关。
- 自定义首页和站点标识照常显示，不替换为虚构品牌或能力。

## 页面决定

- 全站外壳：清晰站名与身份范围、紧凑文字导航、中性选中态；顶栏只放当前路径与已有实用操作。标题与页面主操作在内容区同一行。
- 首页/登录：排版驱动的入口；首页用真实页面入口替换模拟终端响应。登录桌面双栏品牌/表单，手机单栏，无悬浮卡片和装饰球。
- 用户/管理仪表盘：统计合为分栏数据带，保留全部真实值和说明，图表减弱装饰色。快捷入口做成文字操作行。
- 模型广场：模型名称为视觉锚点，分组和系列为次级文字；价格直接排在卡片内，单位紧随价格，复制与详情固定底部；筛选为页签和单一工具栏。卡片、表格、详情共用原价格计算。
- API Keys/账号/分组：统一标题、操作、筛选、列表、分页的连续工作面；桌面保留固定表头/列，手机保留完整数据卡片与局部滚动。
- 使用量/设置：统计、日期控件与明细统一语言；设置页签改为低噪音下划线，设置表单分区去掉重复外框。
