# New API 风格修正

分支：`design/newapi-console`，版本：`0.2.19-yiming.5`。

用户否定上一版连续大面板的视觉效果，并提供实际后台截图。此次参考真实 QuantumNous/new-api 的 `web/src/features/pricing/components/model-card.tsx`（commit `d0322047`），以真实 Astra xhigh 调用完成集中修正，父代理补做后台标题和刷新操作的同排布局。

## 改动

- 模型广场改为独立卡片，16px 间距、细边框、12px 圆角；删除重复的“其他”系列标记，保留名字与分组。
- 模型名称使用15px无衬线字体，价格使用20px无衬线数字；显式设置 Arial／系统字体回退，无新增网络字体。
- 输入和输出价格按标签／数值两行对齐，复制图标与文字同行。
- 调整全局浅色和深色中性表面、侧栏、内容画布和表格密度，移除大面积嵌套白色工作纸。
- 后台内嵌广场的标题与刷新按钮同行，手机亦保留该布局。
- 原有刷新测试增加 PageHeading actions 插槽的真实结构替身，仍执行实际刷新处理并断言返回目录。

模型标识、账号来源、认证、转发、价格解析、上下文档位与分时时段逻辑没有改变。模型广场脚本与改动前逐字一致；ModelPlazaView 仅新增标题组件导入及布局。
